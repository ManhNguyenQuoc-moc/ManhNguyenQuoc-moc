### 🛒 1. **Production-Ready E-commerce Platform**
🔗 GitHub: [ecommerce_Shop_Cosmetics](https://github.com/ManhNguyenQuoc-moc/ecommerce_Shop_Cosmetics) | 🌐 Live Demo: [ecommerce-shop-cosmetics.vercel.app](https://ecommerce-shop-cosmetics.vercel.app)

A fully-featured, performant full-stack e-commerce system built to handle high-concurrency ordering and rich user interaction.

**Highlights:**
- **ACID-Compliant Order Processing**: Implemented strict transactional safety using Prisma transactions to secure data state transitions and stock validation.
- **FEFO Stock Deduction Engine**: Engineered an automated inventory module using database logic to allocate batches closest to expiration first.
- **Real-Time Features & AI**: Integrated Gemini API for automated customer review sentiment analysis coupled with real-time sync via WebSockets.
- **Optimization**: Leveraged Next.js Server-Side Rendering (SSR) and Incremental Static Regeneration (ISR) to optimize loading speeds.

**Tech Stack**: Next.js 16, Node.js, PostgreSQL, Prisma 7, Tailwind CSS, Ant Design, Gemini AI API, WebSockets.
